# ADM Morador

App web para editar a planilha de moradores (Bloco 1 e Bloco 2) e imprimir ou baixar em PDF, em A4 deitado.

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `adm-morador`) e envie o `index.html`.
2. Settings → Pages → Branch `main` / pasta `/ (root)` → Save.
3. O endereço será `https://SEU-USUARIO.github.io/adm-morador/`.

## Uso
- **Bloco 1 / Bloco 2**: edite os apartamentos, adicione, apague ou mude a ordem. Cada apartamento tem contatos (nome, parentesco, telefone), telefone do proprietário e veículos (modelo, placa, vaga alugada de outro apartamento).
- **3 modelos de planilha** (escolha no topo, ao lado de Imprimir): Planilha geral, Telefones e Veículos.
- `*texto*` deixa em negrito. O que estiver entre parênteses, como `( VAZIO )`, sai em negrito automaticamente (dá para desligar em Ajustes).
- **Cabeçalhos**: título, avisos, endereço e a lista de ramais do interfone.
- **Ajustes**: margens da página, tamanho da letra, backup (exportar e importar).
- Os dados ficam salvos no navegador de cada aparelho. Para levar do PC para o celular, use exportar e importar backup.
